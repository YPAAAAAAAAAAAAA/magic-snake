# magic-snake

A clean-room, from-scratch re-implementation of the idea behind **[regomne/magic-snake](https://github.com/regomne/magic-snake)** by [@regomne](https://github.com/regomne). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
